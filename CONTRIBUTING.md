# Contributing

Thanks for considering a contribution.

- Open an issue to discuss substantial changes before sending a pull request.
- Keep the quality gate green: `composer format`, `composer test`, and `composer analyse`
  (Larastan level 7) must all pass, with test coverage at 90% or above.
- Follow the existing code style (Laravel Pint) and PHP 8.4 conventions used in `src/`.
- Use clear, conventional commit messages.
